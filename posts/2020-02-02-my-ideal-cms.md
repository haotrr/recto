---
title: 我理想中的 CMS
summary: 平台无关、内容格式丰富、灵活扩展、主题定制：一个满足自己需求的内容管理系统。
---

Content Management System，内容管理系统，简称 CMS。CMS 主要偏向网络站点后台管理系统，今天在网上搜了下推荐的 CMS，基本上无法满足我的需求，都是一些传统的建站系统，已经无法很好地适应当前这个时代了。在如今这个时代，我们应该有一个更好的内容管理系统，我觉得它至少要满足以下几点。

1. **平台无关。**平台无关有两个方面，一是管理平台不限制在某一平台上，应该是网页、PC、iOS、Android 等等都能登录管理；二是内容分发平台没有限制，自己的博客、站点、公众号，以及其它各大平台等等都支持。

2. **内容格式丰富。**现在除了文字，图片和视频已经成了主流的网络内容，内容管理系统应该要可以管理所有创作素材，可以进行统一管理、统一处理、统一分发。

3. **灵活。**因为不能限制在某一个特殊的平台，所以要可以很好地对系统进行扩展，能够依据自己的需要，对内容管理平台进行二次开发或增加插件，以更好地适应不同新兴的平台需求。具体可参见 VS Code 的插件开发模式，正是依托其丰富的插件，VS Code 才能在如此成熟的编辑器平台中脱颖而出。

4. **主题定制。**在不同平台的内容分发应该尽量统一，但也应该有自己的个性，而这个个性化的设计，就是你自己确定的主题，这个主题应该是可以很好地配置和定制的，每个人都可以依据自己的喜好进行主题改造。

开发一个内核，然后让人们自己开发“插件”，这个是很多软件的成功之道，譬如 Linux、VS Code 等等。我要考虑好好写一个这样的 CMS 来满足自己的需求。
